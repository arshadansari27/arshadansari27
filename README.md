- **Knowledge retrieval systems** — combining RDF triplestores, probabilistic logic (ProbLog), and vector search (pgvector) to build retrieval that handles both explicit relationships and semantic similarity.
- **Macro-financial data infrastructure** — collecting and analyzing inflation expectations, central bank credibility metrics, and macro indicators across 45+ emerging market countries. [Live dashboard →](https://credibility.hikmahtech.in)
- **[KoyraCloud](https://github.com/hikmahtech/koyracloud)** — open-source self-hosted PaaS: push-to-deploy on your own Docker Swarm. The deployment layer behind my products, including my consulting site.
- **Data platform tooling** — Dagster pipelines, DuckDB/Polars for local-first analytics, ClickHouse for time-series, all running on a 6-machine homelab (Proxmox + Docker Swarm).
